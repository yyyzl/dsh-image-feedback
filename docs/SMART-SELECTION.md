# 智能悬停选区

当前是本地开发中的功能，尚未创建新的 GitHub Release，也没有请求市场升级。发布版本 v0.2.0 不包含此功能。

## 使用

在默认“选择”工具下：

- 鼠标悬停在图像元素上，显示尚未确认的推荐边界；预览不创建批注、不保存草稿，也不改变原图。
- 单击采用按下时的推荐范围，意见输入框直接获得焦点。
- 按住并拖动，完全按自己的起止点画框，不吸附推荐范围。开始手动拖动后，即使返回起点附近，也不会变成采用推荐框。
- Shift 跳过推荐；已有批注和图块仍按原有规则编辑、移动。点批注和平移模式不使用智能预选。
- “更多 → 智能预选”可关闭推荐。没有识别结果或后台不可用时，手动画框始终可用。

已接入圆形、椭圆形、胶囊形按钮、三角形、菱形、六边形、梯形、平行四边形候选；保留矩形、圆角卡片与横向文字组。识别预览沿对应轮廓显示，但确认后采用外接矩形范围；这不是抠图，也不引入新的像素切割形状。

## 实现和边界

这是针对图片像素的独立实现，不依赖页面 DOM、操作系统窗口／控件、OCR、网络模型或第三方代码。Snow Apps 中的截图控件识别和像素区域识别是不同路径，本功能借鉴的是“后台准备候选、悬停命中、手动兜底”的体验，而不是复制其实现。

- 图片通过已有授权预览地址解码，缩至最长边 1600 像素、约 120 万像素以内；结果映射回原图坐标。
- 单个 Worker 处理一个任务，最多保留最新的一个待处理任务。切图、关闭功能或离开面板会释放该调用方的任务；没有调用方时终止旧分析。
- 仅缓存最近两张图的完成结果，以算法版本、素材身份、预览地址和尺寸区分。旧 Worker 的事件不能取消新任务。
- 候选结合闭合边界、固定参考底色、局部背景对比、文字行、段落间距和重复列表节奏。普通文字归入合适的行／段落，真实子按钮仍可单独命中；不是 OCR、DOM 或语义物体分割。
- 最多 400 个候选。悬停查询使用缓存，不扫描图片；和已移动图块来源空洞或目标区域冲突的推荐被过滤，避免重复切割。
- 渐变、纹理、模糊、开放边界、极小元素、旋转文字等可能不推荐。对很大的截图，下采样也会降低小元素边界精度。

## 真实界面区块的改进与实测

已使用一份未经主图标注的真实界面截图做私有复现，按实际采样比例检查了选中侧栏行、无边框侧栏行、两个完整聊天段落和头像，基线只有头像通过。无边框区块缺少行／段落候选；灰色选中背景还会因相邻色差连通沿抗锯齿桥接到大背景而被丢弃。该结果与几何样例是否通过是两件事。

已增加固定参考背景、局部背景文字提取、跨文字颜色的重复行与段落分组，以及父子层级命中。改进后同一原图 **5/5 目标**通过：在 12 个文字、时间戳和留白位置命中各自同一区块，选中行／无边框行范围 IoU 约 0.997／0.893，两个段落约 0.925／0.916，头像保持约 0.926。另有 8/8 连续悬停、相邻区块分离、按钮／头像保留检查通过；映射回原图及 2 倍坐标、不同采样插值也核对过。这些是离线像素诊断，不是自动浏览器 E2E。用户随后刷新安装中的插件，确认整行、整段能正确识别。截图软件的原生 UIA／控件树能提供不可见的控件留白；本插件只读取图片像素，因此这类边界是排版推断，不是原页面 DOM 或系统控件的精确还原。真实截图及诊断记录不进入发布包。

## 常见形状的适用范围

识别基于闭合轮廓证据，不是“任何类似图形都算”。当前三角形覆盖上下左右四向，六边形覆盖两种常见朝向；梯形覆盖对称的上窄／下窄和有限的常见比例，平行四边形覆盖有限的常见斜率。胶囊支持横向、纵向。圆形头像需要清晰、闭合、对比足够的边界及相对平整的周围背景，不进行人脸识别。

强旋转、严重透视、遮挡、断边、很小的轮廓（新形状最短边约 18 分析像素以下）、贴图边缘或复杂周围纹理可能退回手动。对未明确覆盖的任意 Logo／不规则多边形不作识别承诺。

## 已验证与未验证

完整 **191 项**本地回归通过，包含新增的明暗背景、混合颜色与加粗文字、短末行段落、重复行与时间戳、子按钮优先、分组容量、背景抗锯齿桥接及字号元数据坐标映射，以及常见形状、填充和描边、方向变体、纹理圆形头像、断边退避、真实轮廓命中和空值保护；原有圆角按钮、细边框、嵌套面板、文字组、坐标映射、Worker 隔离、切图取消、旧事件隔离和手动框选优先也保留。真实 Worker 线程测试不是浏览器 UI E2E；源代码契约也不是渲染测试。

首次实页试用暴露了空草稿与空候选的空值访问错误，已经修复并补回归。随后侧栏可打开，初次矩形候选试用正常。后续反馈指出真正需求是整行／整段区块，而非更多形状模板；已用真实原图复现、修复并获实页确认。单一样例和合成测试不代表所有应用都已达到相同识别水平，特殊排版、复杂背景仍需手动兜底。当前自动浏览器未取得 Harness owner 登录，因此没有伪造 UI 截图或通过替代页面冒充验收。

独立的 [24 格原始测试素材](<../tests/fixtures/smart-shapes.png>) 覆盖 8 类形状 × 填充／描边／深色背景，24/24 同时通过正确类型和外接范围 IoU ≥ 0.90 检查；最差约 0.952，其余约 0.978–1.0。此素材是几何输入，不是插件界面截图。该 1280 × 610 测试图本机冷检测约 217 ms；1280 × 800 的合成重复卡片图输出 80 个候选，Node.js 观测约 89–171 ms（观察值，不是跨设备、浏览器或所有图片的承诺）。大型图的解码时间、Worker 排队和实际鼠标响应仍应在目标设备核对。完整回归用当前测试命令输出的实际数量，见 [测试说明](<TESTING.md>)。
